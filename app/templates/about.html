🛡 AI Intrusion Detection System

Machine Learning Based Network Intrusion Detection

Project Overview

This project is an AI-powered Intrusion Detection System (IDS) that detects malicious network traffic using Machine Learning. It analyzes network datasets and classifies each record as Normal or Attack.

Features

  • ✅ Secure Admin Login
  • ✅ Upload Network Dataset (.csv / .txt)
  • ✅ AI Prediction using Random Forest
  • ✅ Detection Dashboard
  • ✅ Interactive Charts
  • ✅ Detection History
  • ✅ PDF & Excel Report Generation
